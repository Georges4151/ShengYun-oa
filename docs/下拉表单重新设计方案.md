# 主页面下拉表单重新设计方案

## 一、设计目标

### 1.1 实用性提升
- **快速访问**：将最常用的功能提升到显眼位置
- **逻辑分组**：按照业务流程重新组织菜单
- **快捷操作**：添加常用操作的快捷入口
- **视觉优化**：改善视觉层级和交互体验

### 1.2 用户体验优化
- **减少点击**：常用功能一步到位
- **清晰分类**：按照业务模块分组
- **直观导航**：菜单名称明确，易于理解
- **响应反馈**：提供清晰的视觉和交互反馈

## 三、详细设计规范

### 3.1 菜单分组策略

#### 第一优先级：日常操作（文件管理）
- **定位**：最左侧，符合操作习惯
- **内容**：新建、上传、备份、退出
- **图标**：清晰的功能图标

#### 第二优先级：核心业务（项目、账务、票据）
- **定位**：中间位置，强调业务功能
- **内容**：项目管理、账务管理、票据管理
- **特点**：每个模块都有列表、添加、报表三个基础操作

#### 第三优先级：专项功能（材料、分包、电子章）
- **定位**：业务模块右侧
- **内容**：材料管理、分包管理、电子章管理
- **特点**：支持特定的业务场景

#### 第四优先级：辅助功能（报表、系统）
- **定位**：最右侧
- **内容**：报表中心、系统设置
- **特点**：整合统计和系统管理功能

### 3.2 菜单项设计规范

#### 命名规范
- **主菜单**：2-4个汉字，简洁明了
- **子菜单**：3-6个汉字，描述清晰
- **图标**：使用16x16或24x24的图标

#### 功能分组
```
一级菜单（最多7个）
├── 二级菜单（最多10个）
│   ├── 三级菜单（可选，最多5个）
│   └── 操作项
└── 分隔线（逻辑分组）
```

#### 快捷键设置
```
Ctrl+N - 新建账目
Ctrl+U - 上传票据
Ctrl+S - 保存
Ctrl+B - 创建备份
Ctrl+Q - 退出
```

推荐使用JavaFX的现代化组件：

```java
// 使用MenuButton替代Menu

    new MenuItem("新建账目", new ImageView(icon1)),
    new MenuItem("上传票据", new ImageView(icon2)),
    new MenuItem("项目列表", new ImageView(icon3))
);
```
