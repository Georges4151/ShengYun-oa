## 一、账号与权限（IAM）

| 功能点 | 说明 |
|---|---|
| 登录、刷新、登出 | JWT 双令牌，refresh token 一次性使用且并发单飞刷新 |
| 在线会话 | 查询我的登录会话、按会话踢下线 |
| 签名密钥 | 获取当前设备的 HMAC 签名 AppSecret |
| 用户管理 | 增删改查、分配角色、重置密码（仅 SYS_ADMIN） |
| 角色管理 | 角色增删改查、给角色批量授权权限点 |
| 权限管理 | 权限点树增删改查、查询我的权限集合（43 个权限点种子） |
| 设备管理 | 设备列表、登记设备、删除设备 |
| 操作日志 | 按条件分页查询审计日志（仅 SYS_ADMIN） |

对应接口在 `src/main/java/com/ceams/module/iam/controller`，页面为 `apps/web/src/views/iam/AccountView.vue`（用户 / 角色 / 权限 / 设备 / 操作日志五个页签）。

## 二、主数据

| 功能点 | 说明 |
|---|---|
| 分类 | 分类树查询 + 分类增删改查 |
| 往来单位 | 客户 / 供应商等联系人档案增删改查 |
| 材料 | 材料档案、规格、单位、当前单价增删改查 |
| 设备 | 设备台账增删改查 |
| 设备租赁 | 租赁记录增删改查 |

页面：`apps/web/src/views/masterdata/MasterdataView.vue`。

## 三、项目与合同

| 功能点 | 说明 |
|---|---|
| 项目台账 | 项目增删改查、按名称 / 客户 / 状态检索，含合同额、预算额、项目经理 |
| 预算 | 项目预算增删改查，预算使用率与超支标记 |
| 变更 | 变更单增删改查 + 审批通过 / 驳回 |
| 进度款 | 进度款申请增删改查，申请 / 批准 / 实付 / 未付余额 |
| 分包商 | 分包商档案增删改查 |
| 分包合同 | 分包合同增删改查（含 AI 风险提示入口） |
| 结算凭证 | 结算凭证增删改查 |

页面 `apps/web/src/views/project/ProjectView.vue` 七个页签；小程序提供项目列表与项目详情。

## 四、报销管理

| 功能点 | 说明 |
|---|---|
| 票据管理 | 报销单增删改查，支持票据编号、说明、金额、项目归属、附件 |
| 流程动作 | 提交、审批通过、驳回、核验 |
| 记录查询 | 审批记录、核验记录分页查询 |
| AI 预审 | 只读提示接口，列出风险项但不自动驳回 |
| 重复票据识别 | 复用既有只读查询，命中重复票据时提示 |

页面 `apps/web/src/views/expense/ExpenseView.vue`，含票据 / 审批记录 / 核验记录页签和预审面板；小程序有报销待办与报销详情。

## 五、资金管理

| 功能点 | 说明 |
|---|---|
| 付款账户 | 收付款账户增删改查 |
| 收支流水 | 收支流水增删改查，按项目 / 类型 / 状态筛选 |
| 付款交易 | 付款交易增删改查 |
| 成本分摊 | 成本分摊记录增删改查 |
| 付款执行 | `POST /api/v1/payments/execute`，HMAC 高危签名 + SYS_ADMIN/FINANCE 限定 |

页面 `apps/web/src/views/payment/PaymentView.vue`，小程序提供只读账目列表。

## 六、银行对账

| 功能点 | 说明 |
|---|---|
| 银行流水 | 增删改查、批量导入、按账户 / 日期 / 状态检索 |
| 总账 | 总账分录增删改查 |
| 对账匹配 | 发起匹配、单笔对账处理（resolve） |
| 匹配候选 | 只读计算同账户付款交易与总账候选，输出金额差、日期差、匹配分、中文理由，绝不写库 |
| 未对账统计 | 未对账笔数、金额合计与明细（AI 工具） |

页面 `apps/web/src/views/bank/BankView.vue`，流水列表带「匹配建议」弹窗。

## 七、电子印章

| 功能点 | 说明 |
|---|---|
| 印章台账 | 印章增删改查，编码唯一校验，停用 / 归档，删除受引用保护 |
| 用印申请 | 仅 ACTIVE 印章可申请，申请人取当前登录用户，PENDING 可改可撤销 |
| 用印审批 | 基于 PENDING 申请建审批，通过 / 驳回并回写申请状态 |
| PDF 盖章 | 校验印章 ACTIVE + 申请 APPROVED + 印章匹配，PDFBox 叠图并落盘 |
| 盖章记录 | 记录查询、明细、带签名临时下载链接（默认 5 分钟） |
| 使用审计 | 审计流水查询、按期间统计用印次数与用印人分布 |

页面 `apps/web/src/views/seal/SealView.vue` 五个页签。

## 八、通知中心

| 功能点 | 说明 |
|---|---|
| 通知管理 | 通知增删改查、发布、撤销 |
| 我的通知 | 我的通知列表、未读数、单条已读、全部已读 |
| 通知偏好 | 查询我的偏好、更新偏好、删除偏好项 |
| 定向推送 | 日报摘要等按角色（FINANCE / SYS_ADMIN）定向推送并带深链 |

页面 `apps/web/src/views/notification/NotificationView.vue`，小程序有通知列表。

| 功能点 | 说明 |

## 十一、AI 智能办公（Ollama 本地模型）

| 功能点 | 说明 |
|---|---|
| AI 状态 | 查询 Ollama 可用性与模型配置 |
| 智能对话 | SSE 流式对话 + 同步对话两条通道，支持历史消息内嵌工具调用标记 |
| 会话管理 | 我的会话列表、按会话查历史消息 |
| 反馈 | 对回答点赞 / 点踩并留痕 |
| 只读工具（11 个） | 项目台账、预算使用、报销汇总、待审批清单、资金收支、应收进度款、银行未对账、银行匹配候选、印章使用统计、总账/合同类查询 |
| 日报摘要 | 每日 08:00 生成前一天摘要，支持漏跑补录（补录不发通知）、同日覆盖、最新 / 按日期查询、手动生成；模板数字与润色数字双向保全 |
| 报销预审 | 只读规则提示，不做自动驳回 |
| 合同风险提示 | 10 项条款要点 + 8 条确定性规则，可选 AI 复述且数字保全，失败降级 |

Web 端为右侧助手抽屉，小程序有独立「智能助手」页。

## 十二、三端形态

| 端 | 承载功能 |
|---|---|
| Web 管理端 | 上述全部模块，菜单为 主数据 / 项目合同 / 报销 / 资金 / 对账 / 印章 / 通知 / 报表 / 账号 + AI 抽屉 |
| Electron 桌面端 | 复用 Web 全功能，额外提供 USB 印章盘枚举、从 U 盘读取印章图片并算 SHA-256、pdf-lib 本地叠章、refresh token 安全存储、外链拦截 |
| 微信小程序 | 登录、首页、项目列表与详情、报销待办与详情、只读账目、通知、AI 助手 |

## 十三、横切能力

统一响应格式与错误码、分页规范、逻辑删除与乐观锁、自动审计字段、RBAC 三层（菜单/接口/按钮）、HMAC 高危接口防篡改防重放（盖章与付款）、操作日志留痕、JWT 并发刷新去重、生产密钥全部走环境变量、GPG AES256 备份与 7 天保留、deploy 目录 Docker 化部署。
