# CEAMS 多客户端部署清单

## 部署前准备

### ✅ 服务器端(只需执行一次)

- [ ] MySQL服务器已安装并运行
- [ ] MySQL配置已修改(允许远程访问)
- [ ] 防火墙规则已配置
- [ ] 数据库用户已创建
- [ ] 数据库权限已分配
- [ ] 网络连接测试通过

### ✅ 开发电脑(只需执行一次)

- [ ] Maven已安装
- [ ] Java 17已安装
- [ ] 项目代码已同步
- [ ] 打包脚本已准备: `build-client.bat`
- [ ] 配置文件模板已准备: `client-config.properties`

### ✅ 客户端电脑(每台电脑执行一次)

#### 硬件要求
- [ ] Windows 10/11操作系统
- [ ] 4GB以上内存
- [ ] 2GB可用磁盘空间
- [ ] 网络连接正常

#### 软件要求
- [ ] Java 17 Runtime已安装
- [ ] Java环境变量已配置
- [ ] 应用包已复制到本地
- [ ] 配置文件已创建

## 部署检查项

### 第1台客户端电脑验证
- [ ] 应用成功启动
- [ ] 能成功登录系统
- [ ] 能查看和操作数据
- [ ] 数据保存成功
- [ ] 日志无错误

### 第2-N台客户端电脑验证
- [ ] 应用成功启动
- [ ] 能成功登录系统
- [ ] 能看到第1台电脑的操作
- [ ] 数据同步正常
- [ ] 多人同时操作无冲突

## 安全验证

- [ ] 数据库密码已修改(不使用默认密码)
- [ ] 不同角色使用不同权限账户
- [ ] VPN已配置(如使用VPN方案)
- [ ] 防火墙规则已生效
- [ ] 访问日志正常记录

## 培训准备

- [ ] 用户操作手册已准备
- [ ] IT支持人员已培训
- [ ] 常见问题解答已准备
- [ ] 联系方式已分发

## 部署后维护

- [ ] 每周备份数据库
- [ ] 每月安全审计
- [ ] 每季度密码更新
- [ ] 记录任何问题和建议
