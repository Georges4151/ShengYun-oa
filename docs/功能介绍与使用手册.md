## 一、系统概述

CEAMS 是面向建筑企业的一体化管理系统，围绕「项目—合同—资金—票据—印章—档案—人事—审批」主链条，提供 Web 管理端、Electron 桌面端、微信小程序三种访问形态。

| 端 | 定位 | 入口 |
|----|------|------|
| Web 管理端 | 全功能业务办理与后台配置 | 浏览器访问 `http://<服务器>:5173`（开发）或正式域名 |
| 桌面端 | 在 Web 全功能基础上增加 USB 印章盘读取与本地 PDF 盖章 | 安装 NSIS 安装包后启动 |
| 微信小程序 | 移动端轻量办理：打卡、请假、报销、审批、报修、工资条、知识库、AI 助手 | 微信中打开小程序 |

### 1.1 角色与权限

系统采用 RBAC 三层控制（菜单 / 接口 / 按钮），常见角色如下：

| 角色 | 主要权限范围 |
|------|--------------|
| SYS_ADMIN 系统管理员 | 全部模块、账号与权限、操作日志、存储信息、流程模板、公开知识库 |
| FINANCE 财务 | 报销核验、资金付款执行、银行对账、财务报表、AI 日报 |
| HR 人事 | 员工档案、合同、考勤、薪酬、绩效 |
| 项目经理 / 业务人员 | 项目与合同、进度款、报销提交、待办审批 |
| 普通员工 | 个人待办、报销、请假打卡、报修、知识库、通知 |

> 菜单与按钮按当前账号的权限点动态显示，看不到某菜单属正常现象，请联系管理员分配权限。

## 二、通用使用说明

### 2.1 登录

1. 打开系统登录页，输入账号与密码。
2. 可选择「企业微信扫码登录」（需管理员启用企业微信集成）。
3. 登录成功后进入默认首页；访问无权限页面会被拦截并提示。

令牌策略：访问令牌 15 分钟有效，过期后自动用刷新令牌续期，刷新令牌一次性使用；多人同时触发刷新时系统自动合并为一次，避免重复失效。

### 2.2 界面结构

- **左侧菜单**：主数据、项目合同、人事、行政后勤、文档知识库、企业微信集成、待办中心、报销、资金、对账、印章、通知、报表、账号。
- **顶部栏**：全局搜索、通知入口（未读数）、个人头像（个人资料 / 退出登录）。
- **右侧 AI 助手抽屉**：随时唤起智能问答与数据查询。

### 2.3 个人资料

「账号 → 个人资料」可维护姓名、联系方式、头像（支持上传，系统校验格式与大小并自动清理旧头像），查看当前登录设备与在线会话，可对异常会话执行下线。

### 2.4 通知

顶部铃铛进入「通知」，展示未读数，支持单条已读与全部已读。通知分为审批、人力、行政、文档四类，可按类型筛选。小程序同步提供通知列表。

### 2.5 操作日志

系统对关键操作留痕（登录、审批、盖章、导出、删除等），管理员可在「账号 → 操作日志」按条件检索。

## 三、业务模块详细介绍

### 3.1 主数据

页面：主数据，五个页签。

| 页签 | 功能 |
|------|------|
| 分类 | 分类树查询与维护，供材料、往来单位等引用 |
| 往来单位 | 客户、供应商档案的增删改查 |
| 材料 | 材料名称、规格、计量单位、当前单价维护 |
| 设备 | 设备台账维护 |
| 设备租赁 | 租赁记录维护，列表展示设备名称、项目名称、出租方名称 |

操作：点击「新增」填写表单保存；行内「编辑 / 删除」；列表支持关键字与条件筛选、分页。删除被引用数据时系统会拒绝并提示原因。

### 3.2 项目与合同

页面：项目合同，七个页签。

| 页签 | 功能 |
|------|------|
| 项目 | 项目台账：合同额、预算额、项目经理、状态，支持按名称 / 客户 / 状态检索 |
| 预算 | 项目预算维护，展示预算使用率与超支提示 |
| 变更 | 变更单登记，提交后走审批，审批通过 / 驳回 |
| 进度款 | 申请金额、已批准、已实付、未付余额管理 |
| 分包商 | 分包商档案维护 |
| 分包合同 | 分包合同维护（含合同文件上传与关联名称展示），支持 AI 合同风险提示 |
| 结算凭证 | 结算凭证维护与凭证文件管理 |

典型流程：新建项目 → 录入预算 → 发生变更时提交变更单并审批 → 按节点申请进度款 → 审批后登记实付。

> 文件上传后若取消弹窗或保存失败，系统会自动清理本次未保存的临时文件；被合同或凭证引用的文件禁止删除。

### 3.3 报销管理

页面：报销，三个页签 + AI 预审面板。

| 页签 / 能力 | 功能 |
|-------------|------|
| 票据 | 报销单增删改查：票据编号、说明、金额、项目归属、票据附件（支持拖拽上传，1～6 张） |
| 审批记录 | 查看审批流转记录 |
| 核验记录 | 财务核验记录 |
| 流程动作 | 提交、审批通过、驳回、核验 |
| AI 预审 | 只读风险提示（金额、重复票据、要素缺失等），只提示不驳回 |
| 重复票据识别 | 命中重复票据时提示，不阻断提交 |

操作说明：新建票据 → 上传票据图片 → 提交进入审批 → 审批人处理 → 财务核验。小程序支持「发起报销」与「报销详情」。

### 3.4 资金管理

页面：资金，四个页签。

| 页签 | 功能 |
|------|------|
| 付款账户 | 收付款账户维护 |
| 收支流水 | 收支流水登记，按项目 / 类型 / 状态筛选 |
| 付款交易 | 付款交易登记与查询 |
| 成本分摊 | 成本分摊记录维护，用于项目成本归集 |

付款执行属于高危操作，仅 SYS_ADMIN / FINANCE 可执行，且请求必须携带设备签名（`X-Sign` / `X-Timestamp` / `X-Nonce`），防止篡改与重放。

### 3.5 银行对账

页面：对账，三个页签。

| 页签 | 功能 |
|------|------|
| 银行流水 | 流水增删改查、批量导入（Excel/CSV）、按账户 / 日期 / 状态检索 |
| 总账 | 总账分录维护 |
| 对账结果 | 发起匹配、单笔对账处理、查看匹配结果 |

「匹配建议」弹窗会根据同账户付款交易与总账计算候选，展示金额差、日期差、匹配分与中文理由。该计算为只读，不会修改数据。

操作流程：导入银行流水 → 在流水行点击「匹配建议」→ 选择候选 → 发起对账 → 在对账结果中确认或调整。

### 3.6 电子印章

页面：印章，五个页签，覆盖「建印 → 申请 → 审批 → 盖章 → 审计」闭环。

| 页签 | 功能 |
|------|------|
| 电子印章 | 印章台账：编码唯一校验、启停用、归档；被引用的印章禁止删除 |
| 用印申请 | 仅 ACTIVE 印章可申请，申请人自动取当前登录用户；PENDING 状态可修改或撤销 |
| 用印审批 | 基于 PENDING 申请创建审批，通过 / 驳回结果回写申请状态 |
| 盖章记录 | 盖章结果查询与下载（带签名的临时链接，默认 5 分钟有效） |
| 使用审计 | 用印流水查询，按期间统计用印次数与用印人分布 |

盖章前置校验：印章必须 ACTIVE、申请必须 APPROVED、申请印章与请求印章一致，三者缺一不可；接口强制 HMAC 签名。桌面端可从 USB 印章盘读取印章图片并计算 SHA-256 后本地叠章。

### 3.7 待办中心与流程审批

页面：待办中心，六个页签。

| 页签 | 功能 |
|------|------|
| 我的待办 | 待我处理的审批任务，可打开详情执行通过 / 驳回 / 转办 |
| 我发起 | 我发起的流程实例及当前进度 |
| 我已办 | 我处理过的任务 |
| 抄送我的 | 抄送给我的流程 |
| 代理设置 | 设置审批代理人（休假期间代处理） |
| 流程模板 | 仅管理员可见：模板新增 / 修改 / 停用 / 删除、版本管理、节点与条件配置 |

注意事项：模板若已被流程实例引用，删除会被拒绝，请改为停用；模板与版本的增删均写入审计日志并有独立权限点。

### 3.8 人事管理

页面：人事，六个页签。

| 页签 | 功能 |
|------|------|
| 员工档案 | 员工基本信息、部门、岗位、入职离职；小程序可查看「我的档案」 |
| 合同台账 | 劳动合同登记、到期提醒、合同文件上传与下载 |
| 考勤管理 | 考勤记录查询、补卡处理；小程序支持「打卡」 |
| 薪酬台账 | 员工薪酬标准与调整记录 |
| 绩效管理 | 绩效指标与考评单，员工自评 → 主管评分 → 终审（APPROVED） |
| 工资核算 | 工资核算与工资条生成，小程序可查看「我的工资条」 |

小程序闭环：打卡、请假申请、绩效自评、查看档案与工资条。

### 3.9 行政后勤

页面：行政后勤，按权限显示六个页签。

| 页签 | 功能 |
|------|------|
| 资产台账 | 资产入库、领用、借用、维修、报废；逾期未归还高亮提示 |
| 易耗品 | 易耗品出入库与领用管理 |
| 车辆 | 车辆台账与用车申请审批 |
| 会议室 | 会议室维护与预定管理 |
| 访客 | 访客登记与二维码核销 |
| 报修 | 报修工单：报修（1～6 张图片必填）→ 派单 → 完工（1～6 张图片必填）→ 用户验收 |

小程序提供资产领用、用车申请、会议室预定、报修申请、我的报修与访客核销。

### 3.10 文档知识库

页面：文档知识库。

- **知识库类型**：个人库、部门库、项目库、公开库。公开库仅 SYS_ADMIN 可创建，其他类型普通用户可创建。
- **目录与文件**：左侧目录树，右侧文件列表；支持新建目录、上传文件、重命名、移动、删除。
- **版本管理**：文件支持多版本，可查看版本历史、来源、变更说明、上传人与时间，支持回滚与新版本上传。
- **在线编辑**：接入 OnlyOffice，可在浏览器内编辑 Office 文档；编辑时加锁，关闭时释放编辑锁。
- **知识库检索**：按权限过滤后全文检索文档片段，返回文件名、目录路径、片段内容与文件 ID；无结果时明确提示「知识库中未找到」，不会编造。

注意事项：删除文件会同步释放编辑锁；被业务引用的文件禁止删除；ID 字段以字符串返回，避免前端精度丢失。

### 3.11 通知中心

- **通知管理**（管理员）：创建通知、发布、撤销。
- **我的通知**：未读数、单条已读、全部已读，按类型（审批 / 人力 / 行政 / 文档）筛选。
- **通知偏好**：按类型设置是否接收，支持删除偏好项。

AI 日报摘要仅向 FINANCE / SYS_ADMIN 角色推送，并带深链直达。

### 3.12 报表

页面：报表。

| 页签 | 内容 |
|------|------|
| 财务报表 | 按流水 / 交易来源汇总的收支明细 |
| 项目成本 | 合同额、预算、变更、已付进度款、成本分摊、实际发生额 |
| 材料报表 | 材料单价、采购 / 领用笔数与金额合计 |
| 人力成本 | 按部门与期间的人力成本汇总 |
| 绩效考核 | 终审通过考评单的平均分与分布 |
| 行政资产 | 资产状态分布、借用与逾期情况 |
| 审批效率 | 流程节点积压、平均处理时长 |

页面顶部仪表盘展示待审批报销、待审批用印、未读通知、项目数量、本月收支与累计收支。报表支持导出 Excel（中文文件名按 RFC 5987 编码，各浏览器可正常保存）。

### 3.13 账号与权限

页面：账号，七个页签（部分仅管理员可见）。

| 页签 | 功能 |
|------|------|
| 个人资料 | 本人信息、头像、在线会话 |
| 用户 | 用户增删改查、分配角色、重置密码（仅 SYS_ADMIN） |
| 角色 | 角色维护与批量授权 |
| 权限 | 权限点树维护（编码唯一、父节点校验、防环） |
| 设备 | 设备登记、列表、删除 |
| 操作日志 | 审计日志检索（仅 SYS_ADMIN） |
| 存储 | 上传文件占用与目录统计（仅 SYS_ADMIN） |

### 3.14 企业微信集成

页面：企业微信集成（需具备 `integration:wecom:view` 权限）。

- 扫码登录配置：生成企业微信授权二维码，回调后自动登录。
- 通讯录同步：触发同步、查看同步批次与结果。
- 应用消息：查看推送记录与重投失败消息。

配置由环境变量控制，默认关闭；未启用时页面会提示「企业微信扫码登录未启用」。

### 3.15 AI 智能办公

基于本地 Ollama，默认关闭，由环境变量 `AI_ENABLED` 控制。

| 能力 | 说明 |
|------|------|
| 智能对话 | 右侧助手抽屉，支持流式（SSE）与同步两种通道、多会话与历史消息 |
| 只读数据工具 | 项目汇总、预算使用、报销汇总、待审批、资金收支、应收进度款、未对账、匹配候选、印章使用、人力、资产、考勤、车辆、费用、现金流等查询，只读不写库 |
| 日报摘要 | 每日 08:00 生成前一日摘要；漏跑可补录（补录不发通知）；同日重复生成覆盖 |
| 票据识别 | 上传票据图片识别金额、日期、抬头等要素（视觉模型） |
| 报销预审 | 只读规则提示，不自动驳回 |
| 合同风险提示 | 确定性规则 + 关键条款要点，模型润色失败自动回退模板 |
| 知识库问答 | 先按权限过滤片段再回答，回答附带可点击来源引用 |

使用建议：直接输入业务问题（如「本月未对账金额是多少」），助手会调用只读工具取数并给出结论；涉及写操作仍需在对应业务页面完成。

## 四、微信小程序使用说明

### 4.1 登录与首页

使用与 Web 相同的账号密码登录。首页按当前账号权限动态展示入口（我的待办、项目、报销、知识库、通知、打卡、请假、档案、工资条、绩效自评、资产领用、用车、会议室、报修、访客核销等），右上角头像可进入个人档案并更换头像。

### 4.2 常用操作

| 场景 | 操作路径 |
|------|----------|
| 审批 | 首页 → 我的待办 → 选择待办 → 通过 / 驳回并填写意见 |
| 报销 | 首页 → 发起报销 → 填写信息并上传票据 → 提交 |
| 打卡 | 首页 → 打卡 |
| 请假 | 首页 → 请假申请 → 选择类型与时间 → 提交审批 |
| 报修 | 首页 → 报修申请 → 填写问题并上传 1～6 张图片 → 提交；在「我的报修」查看进度、上传完工图片、验收 |
| 知识库 | 首页 → 知识库 → 选择目录 → 预览文件（图片直接预览，PDF 用文档打开） |
| 工资条 | 首页 → 我的工资条 |
| 绩效自评 | 首页 → 绩效自评 → 按指标打分 0～100 并提交 |
| AI 助手 | 首页 → 智能助手 |

### 4.3 注意事项

- 小程序需在微信开发者工具中勾选「不校验合法域名」（本地联调），真机调试需将接口地址改为电脑局域网 IP。
- 接口域名变更后需在开发者工具中「清除全部缓存」再编译，避免旧地址残留。
- 需要登录态的图片资源通过带令牌请求加载，不直接使用图片链接。

## 五、桌面端使用说明

- 桌面端复用 Web 全部功能，启动后使用相同账号登录。
- 额外能力：枚举本机 USB 印章盘、读取印章图片并计算 SHA-256 指纹、使用 pdf-lib 在本地完成 PDF 叠章后上传。
- 令牌安全存储于本地，不落明文；外部链接默认拦截。
- 安装包由 electron-builder 生成（NSIS），支持自定义安装目录与创建桌面快捷方式。

## 六、典型业务流程速查

**报销**：员工新建票据并上传附件 → 提交 → 审批人处理 → 财务核验 → 入账。提交前可查看 AI 预审提示，但系统不会自动驳回。

**用印**：管理员建印并启用 → 申请人选择 ACTIVE 印章提交用印申请 → 审批人通过 → 执行 PDF 盖章（桌面端可用 U 盘印章）→ 生成盖章记录与审计流水 → 通过限时签名链接下载成品。

**合同**：主数据维护往来单位 → 项目合同页签录入分包商与合同、上传合同文件 → AI 风险提示自查 → 变更 / 进度款按流程审批。

**对账**：导入银行流水 → 查看匹配建议 → 发起对账 → 在对账结果中确认；未对账情况可向 AI 助手询问。

**知识库**：创建知识库目录 → 上传文档（自动抽取正文与分块索引）→ 需要时在线编辑 → 通过检索或 AI 助手按权限查找内容。

## 七、常见问题

| 问题 | 处理方式 |
|------|----------|
| 登录提示「账号或密码错误」 | 核对密码；新建账号默认密码为 `123456`，可在「账号 → 用户」重置 |
| 提示「登录已失效，请重新登录」 | 令牌失效或刷新令牌被撤销，重新登录即可 |
| 页面提示「无权限执行该操作」 | 当前账号缺少权限点，请联系管理员在「角色」中授权 |
| 看不到某个菜单 | 菜单按权限动态渲染，确认角色授权后再刷新 |
| 上传文件失败 | 检查扩展名是否在白名单、文件大小是否超限（单文件 20MB） |
| 文档在线编辑打不开 | OnlyOffice 服务不可用时会降级为 503，文件列表与下载仍可用，请联系管理员 |
| AI 助手不可用 | AI 默认关闭，需管理员启用并确保 Ollama 模型已拉取 |
| 小程序请求不到接口 | 检查接口地址配置与「不校验合法域名」设置，必要时清除缓存重编译 |
| 报修无法提交 | 报修与完工阶段均要求上传 1～6 张图片 |
| 用印申请提交失败 | 确认印章为启用状态、申请信息完整，且账号具备用印权限 |
