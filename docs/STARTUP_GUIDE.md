# 应用程序启动指南

## 🚀 启动方式

### 方式1：使用Maven启动（推荐）

```bash
# 进入项目目录
cd e:\sxassist

# 使用Maven启动
mvn spring-boot:run
```

### 方式2：使用IDE启动

1. 在IDE中打开项目
2. 找到 `CeamsApplication.java` 文件
3. 右键点击 `main` 方法
4. 选择"运行"或"调试"

### 方式3：打包后启动

```bash
# 编译项目
mvn clean package

# 运行打包后的JAR文件
java -jar target/ceams-*.jar
```

## 🐛 常见问题

### Q1: 启动时显示空白页面

**原因**：FXML文件路径错误或文件不存在

**解决方法**：
1. 检查FXML文件是否存在于 `src/main/resources/fxml/` 目录
2. 检查FXML文件名是否正确
3. 检查控制器类名是否正确

### Q2: 样式没有生效

**原因**：CSS文件路径错误或文件不存在

**解决方法**：
1. 检查CSS文件是否存在于 `src/main/resources/css/` 目录
2. 检查CSS文件名是否正确
3. 清理并重新编译项目

### Q3: 控制器方法没有执行

**原因**：FXML中的 `fx:id` 与控制器中的字段名不匹配

**解决方法**：
1. 检查FXML中的 `fx:id` 属性
2. 检查控制器中的 `@FXML` 注解字段
3. 确保名称完全匹配（区分大小写）

### Q4: 点击按钮没有反应

**原因**：FXML中的 `onAction` 与控制器中的方法名不匹配

**解决方法**：
1. 检查FXML中的 `onAction` 属性
2. 检查控制器中的 `@FXML` 注解方法
3. 确保方法名完全匹配（区分大小写）

### Q5: 数据没有显示

**原因**：Service注入失败或数据加载失败

**解决方法**：
1. 检查Service是否正确注入
2. 检查数据库连接是否正常
3. 检查Service方法是否正确实现
4. 查看控制台日志获取错误信息

### Q6: 编译失败

**原因**：代码语法错误或依赖缺失

**解决方法**：
1. 查看编译错误信息
2. 修复语法错误
3. 检查依赖是否完整
4. 清理并重新编译：`mvn clean compile`

### Q7: 端口被占用

**原因**：端口9095已被其他程序占用

**解决方法**：
1. 查找占用端口的程序并关闭
2. 修改配置文件中的端口号
3. 使用命令行参数指定端口：`--server.port=8080`
